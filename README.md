IntelliText: General-Domain Text Classification Chatbot

Phase 1: NLP Preprocessing
This repository contains the first phase of the IntelliText Chatbot project. The goal is to preprocess raw text data to prepare it for machine learning classifiers.

Techniques Implemented (via NLTK):

Tokenization

Stopword Removal

POS Tagging

Stemming & Lemmatization

Dataset: A synthetic dataset consisting of customer queries across three categories: Technical Support, Billing, and Shipping.
